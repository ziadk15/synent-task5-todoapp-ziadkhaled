# To-Do App

A simple and responsive To-Do List app built using HTML, CSS, and JavaScript.

## Features

- Add new tasks  
- Edit tasks  
- Delete tasks  
- Mark tasks as completed  
- Clear all tasks  
- Search tasks  
- Data saved in localStorage  

## Technologies

- HTML  
- CSS  
- JavaScript
